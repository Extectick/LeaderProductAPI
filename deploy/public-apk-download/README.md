# Постоянная ссылка на production APK

Публичный адрес: `https://api.leader-product.ru/download`.

Страница без авторизации вызывает существующий `GET /updates/check` с
`platform=android`, `channel=prod`, `versionCode=0`, получает свежую ссылку и
автоматически начинает скачивание. Резервная кнопка доступна, если браузер не
начал скачивание. Повторная проверка получает новый URL, а не повторяет старый.
Поделитесь адресом страницы, а не временным URL из адреса загрузки APK.

Сам адрес страницы не содержит токена и не имеет срока действия. Объекты S3
остаются приватными. Новый APK выбирается после его публикации в `AppUpdate`;
OTA не является новым APK. Ошибка API не приводит к выдаче старого файла.

## Установка

Загрузить `index.html`, `app.js`, `nginx.conf`, `install.sh` в отдельный каталог
сервера. Из этого каталога выполнить `sh install.sh` от root. Скрипт добавляет
точные маршруты `/download`, `/download/`, `/download/app.js` только в HTTPS
виртуальный сервер `api.leader-product.ru`, проверяет nginx и делает graceful
reload. API, Docker, PostgreSQL и 1С не изменяются.

Предыдущее состояние сохраняется в `/var/backups/leader-apk-download/<UTC>/`.
При неудачной проверке конфигурации или HTTP скрипт восстанавливает его.
Существующие предупреждения nginx о TLS в другом virtual host не относятся к
этой странице и этим изменением не исправляются.

## Проверка

```powershell
node --test deploy/public-apk-download/download.test.cjs
node deploy/public-apk-download/verify-live.cjs
```

Вторая команда проверяет публичный HTML/JS, отсутствие кеширования, ответ API,
полную загрузку APK с проверкой размера/SHA-256 и health API. Подписанные URL и
токены не печатаются. Это проверка загрузки, не установки APK на телефон.

Установлено 08.10.2026 по времени Омска. На момент проверки опубликован APK
0.1.26 (25). Новый APK и полный dev API этим изменением не выпускались.
