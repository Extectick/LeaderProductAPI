# Обслуживание PostgreSQL LeaderAPI

На docker-01 пользовательский таймер запускает `run.py prod maintain` один раз в сутки по местному времени. SQL выполняется через локальный сокет рабочего контейнера PostgreSQL. Размеры всех таблиц и индексов, накопительные счётчики и время последнего запуска PostgreSQL сохраняются на хосте в `~/.local/state/leader-db-maintenance/prod/YYYY-MM-DD.json` за 180 дней. В массиве таблицы по порядку записаны общий размер в байтах, размер индексов, оценки количества живых и мёртвых строк, накопительные счётчики вставок, обновлений и удалений. Для анализа суточных изменений учитывайте сброс статистики.

Очистка refresh-токенов проходит короткими транзакциями до 500 строк, максимум 16 000 за запуск. Сохраняются 30 дней после самого позднего срока действия, использования, окончания льготного периода или создания токена, включая связанные активные семейства и ссылки от свежих токенов. Повторный запуск продолжает обработку. В снимок записываются только агрегаты.

Установка на docker-01 под пользователем обслуживания:

```sh
install -d -m 700 ~/.local/lib/leader-db-maintenance ~/.config/systemd/user
install -m 600 run.py compact.py table-health.sql expire-tokens.sql ~/.local/lib/leader-db-maintenance/
install -m 644 leader-db-maintenance.{service,timer} ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now leader-db-maintenance.timer
```

Для изолированной копии укажите имя её контейнера в `LEADER_AUDIT_COPY_CONTAINER`. Имя базы копии — `lp_audit_copy`. Для одного замера выполните `python3 run.py copy sample --state /path/to/private/state`. Для проверки очистки замените `sample` на `maintain`.

Разовое уплотнение одной из четырёх промежуточных таблиц запускается вручную через `python3 compact.py copy OnecStageAgreement`. Утилита проверяет отсутствие конфликтующих читателей и обслуживания обмена, берёт короткую блокировку NOWAIT и сверяет содержимое и каталог перед фиксацией. Если выигрыша в размере нет или исчерпано время, транзакция откатывается. Утилита не входит в таймер.
