# Проверка поиска и источников в «Помощи»

## Решение пользователя

31.10.2026: развитие интерфейса документов в админке отложено. Достаточно положить файл в папку компании. Провайдер будущих ответов — **OpenAI API**; ключ будет добавлен позже. До этого документы не отправляются во внешнюю модель.

## Как проверить сейчас

1. Сохранить TXT, MD, DOCX или PDF с текстовым слоем в `V:\Leader-Product-Cloud\База знаний\Материалы компании` или её тематическую подпапку.
2. Дождаться синхронизации клиента Nextcloud. Сервер обходит папки раз в минуту, затем извлекает и индексирует текст.
3. В обычном приложении, подключённом к **dev API**, создать обращение с вопросом по документу. Локальный дизайн-стенд Help с собственными fixtures для этого не подходит.
4. Получить выдержки из найденных документов: название, путь и номер версии. Это **проверка поиска**, а не генерация ответа языковой моделью.
5. Уточнение во время обработки отменяет устаревшее задание. После ответа можно уточнить вопрос: поиск учитывает первое сообщение и последние сообщения автора.
6. Если инструкция не помогла, написать «Не помогло» или «Подключите IT». При отсутствии доступного материала либо недоступности источника обращение также передаётся в IT с сохранением переписки.

Изменение файла создаёт новую версию. Старые выдержки остаются частью уже отправленной переписки; новый ответ использует актуальную доступную версию. Удаление или перенос в `Архив` исключают документ из будущих ответов после сверки источника.

`Рабочая область ИИ` и `Архив` не участвуют в ответах. Новые файлы в «Материалы компании» считаются общими знаниями сотрудников, имеющих доступ к «Помощи». Уже установленные вручную ограничения и отзыв публикации сохраняются; ограниченные документы пока исключены именно из автоматических ответов Help.

## Серверный контракт

```dotenv
HELP_AI_ENABLED=true
HELP_AI_PROVIDER=knowledge
KNOWLEDGE_ENABLED=true
KNOWLEDGE_PUBLICATION_MODE=folder
```

Параметры чтения Nextcloud берутся из существующего приватного `knowledge.worker.env`. Ключи S3 и пароль администратора индексатору не нужны. Новых миграций для этого этапа нет.

- `knowledge.folder.ts`: атомарная публикация готовой версии и аудит `FOLDER_PUBLISHED`; обработка ранее готовых файлов пакетами по 100; ручной отзыв имеет приоритет.
- `help.knowledge.ts`: запрос по русскому/простому полнотекстовому индексу, до трёх документов и двух фрагментов на документ, суммарно до 9 500 символов выдержек. Это лексический поиск; embeddings и семантическое ранжирование пока не подключены.
- `help.assistant.ts`: прежняя долговечная очередь, lease, защита от устаревшего исполнителя, socket-журнал и outbox уведомлений. Телефон не выполняет поиск и не должен оставаться открытым.
- Ответ хранит `assistantState.answerMode=knowledge-excerpts` и `sources` с ID документа/версии, номером ревизии и защищённым `sourceUrl`. Название/версия/путь также входят в обычный текст, поэтому новый APK для чтения выдержек не требуется.
- Перед сохранением ответа версия, доступность и общий доступ проверяются ещё раз под блокировками источника и документов. Отозванные или изменённые источники приводят к повторной подготовке, а не сохранению старого ответа.
- Передача в IT атомарна с финальным ответом: `itRequested=true`, событие `IT_REQUESTED`; штатный журнал уведомлений уведомляет участников и IT согласно существующим правилам.

Нет автоматических действий в 1С, выполнения инструкций из документов, внешних API-запросов к ИИ или обучения модели.

## Выпуск и откат

Dev overlay: `deploy/knowledge/compose.help-knowledge-dev.yml`, после текущих overlays API, Help и knowledge. Меняются только dev API, `knowledge-worker` и `help-assistant-worker`; PostgreSQL, Redis, production и VPN не пересоздаются.

Перед выпуском сохраняются текущие настройки/образы и читаемая резервная копия dev БД. Откат кода — прежние образы и окружение этих трёх сервисов. Не восстанавливать всю БД поверх новых обращений и не удалять таблицы. При необходимости временно остановить приём новых заданий: `HELP_AI_ENABLED=false`; выключение folder mode прекращает будущую автопубликацию, но само по себе не отзывает уже опубликованные документы.

Он не запускает API и доставщик уведомлений: проверяются строки сообщений, событий и outbox без отправок реальным пользователям.
